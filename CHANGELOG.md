# История изменений Pabla IDE

## [2.0.0] - 2024-12-19

### Добавлено
- ✅ **Система тем через JSON файлы**
  - 5 встроенных тем: Тёмная, Светлая, Синяя тёмная, Dracula, Зелёная
  - Класс `ThemeManager` для управления темами
  - Поддержка всех основных виджетов Qt
  - Гибкая структура для добавления новых тем

- ✅ **Система языков интерфейса**
  - Поддержка русского и английского языков
  - Класс `LanguageManager` для управления переводами
  - JSON файлы с переводами для каждого языка
  - Автоматическое обновление интерфейса при смене языка

- ✅ **Улучшенный диалог настроек**
  - Выпадающий список с доступными темами
  - Выпадающий список с доступными языками
  - Предварительный просмотр темы при выборе
  - Описания тем в списке
  - Сохранение выбранной темы и языка

- ✅ **Исправления терминала**
  - Команда `help` теперь работает корректно
  - Улучшенная обработка команд
  - Команда `themes` для просмотра доступных тем
  - Команда `languages` для просмотра доступных языков
  - Команда `language <код>` для смены языка

- ✅ **Инструменты разработки**
  - Скрипт `add_theme.py` для управления темами
  - Batch файл `build.bat` для сборки
  - Подробная документация

### Изменено
- 🔄 Рефакторинг системы тем
- 🔄 Улучшен пользовательский интерфейс
- 🔄 Обновлена документация

### Исправлено
- 🐛 Ошибка с командой `help` в терминале
- 🐛 Проблемы с загрузкой тем
- 🐛 Улучшена обработка ошибок
