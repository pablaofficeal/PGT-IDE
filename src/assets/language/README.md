# Система языков Pabla IDE

## Обзор

Pabla IDE поддерживает многоязычный интерфейс через JSON файлы. Каждый язык представлен отдельным файлом в формате `language_<код>.json`.

## Структура файла языка

```json
{
  "interface": {
    "window_title": "Pabla IDE",
    "file_menu": "File",
    "new_file": "New File",
    // ... другие элементы интерфейса
  },
  "dialogs": {
    "settings_title": "Pabla IDE Settings",
    "theme_label": "Select interface theme:",
    // ... диалоги
  },
  "messages": {
    "file_open_error": "Failed to open file.",
    "theme_activated": "Theme '{0}' activated.",
    // ... сообщения с параметрами
  },
  "commands": {
    "help_title": "Available commands:",
    "help_help": "help - show command list",
    // ... команды терминала
  },
  "languages": {
    "ru": "Русский",
    "en": "English",
    "de": "Deutsch"
    // ... названия языков
  }
}
```

## Поддерживаемые языки

- **ru** - Русский
- **en** - English

## Добавление нового языка

### Через скрипт (рекомендуется)
```bash
python add_language.py add
```

### Вручную
1. Создайте файл `language_<код>.json` в папке `src/assets/language/`
2. Скопируйте структуру из существующего файла
3. Замените все значения на переводы для вашего языка
4. Добавьте название языка в секцию `languages`

## Параметры в переводах

Для сообщений с параметрами используйте плейсхолдеры `{0}`, `{1}`, и т.д.:

```json
{
  "messages": {
    "theme_activated": "Тема '{0}' активирована.",
    "file_opened": "Файл '{0}' открыт в папке '{1}'."
  }
}
```

## Команды терминала

- `languages` - показать доступные языки
- `language <код>` - изменить язык (например: `language en`)

## Управление через меню

Файл → Настройки → Выберите язык из выпадающего списка

## Автоматическое сохранение

Выбранный язык автоматически сохраняется в настройках и восстанавливается при следующем запуске.

## Структура папок

```
src/assets/language/
├── language_ru.json    # Русский
├── language_en.json    # Английский
└── README.md          # Эта документация
```

## Советы по переводу

1. **Сохраняйте консистентность** - используйте одинаковые термины для одинаковых понятий
2. **Учитывайте длину** - некоторые элементы интерфейса имеют ограниченное пространство
3. **Тестируйте** - проверяйте, как переводы выглядят в интерфейсе
4. **Используйте контекст** - учитывайте, где и как используется каждый элемент

## Примеры переводов

### Интерфейс
```json
{
  "interface": {
    "window_title": "Pabla IDE",
    "file_menu": "Файл",
    "new_file": "Новый файл",
    "open_file": "Открыть файл",
    "save_file": "Сохранить файл",
    "settings": "Настройки"
  }
}
```

### Сообщения с параметрами
```json
{
  "messages": {
    "theme_activated": "Тема '{0}' активирована.",
    "file_saved": "Файл '{0}' сохранен."
  }
}
```

### Команды терминала
```json
{
  "commands": {
    "help_title": "Доступные команды:",
    "help_help": "help - показать список команд",
    "help_themes": "themes - показать доступные темы"
  }
}
```
