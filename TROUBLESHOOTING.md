# Устранение проблем Pabla IDE

## Проблема: "Не удалось открыть файл тем"

### Симптомы
```
Не удалось открыть файл тем: src/assets/themes/themes.json
```

### Причины
- Приложение запускается не из правильной папки
- Файлы тем не скопированы в папку сборки
- Неправильный относительный путь

### Решения

#### 1. Используйте скрипт запуска
```cmd
run.bat
```

#### 2. Запускайте из папки build
```cmd
cd build
untitled20.exe
```

#### 3. Пересоберите проект
```cmd
build.bat
```

#### 4. Проверьте наличие файлов тем
```cmd
dir build\assets\themes
```

Должны быть файлы:
- `themes.json`
- `README.md`

## Проблема: Приложение не запускается

### Симптомы
```
Process finished with exit code -1073741510 (0xC000013A)
```

### Решения

#### 1. Проверьте зависимости Qt
Убедитесь, что в папке `build/` есть файлы:
- `Qt6Core.dll`
- `Qt6Gui.dll`
- `Qt6Widgets.dll`
- `plugins/platforms/qwindows.dll`

#### 2. Пересоберите проект
```cmd
build.bat
```

#### 3. Запустите из правильной папки
```cmd
run.bat
```

## Проблема: Терминал не работает

### Симптомы
- Команды не выполняются
- Терминал не отвечает

### Решения

#### 1. Проверьте команду help
Введите в терминал:
```
help
```

#### 2. Перезапустите приложение
Закройте и откройте приложение заново.

## Проблема: Темы не применяются

### Симптомы
- Тема не меняется при выборе
- Ошибки в настройках

### Решения

#### 1. Проверьте файл тем
```cmd
python add_theme.py list
```

#### 2. Пересоберите проект
```cmd
build.bat
```

#### 3. Проверьте права доступа
Убедитесь, что у приложения есть права на чтение файлов тем.

## Общие рекомендации

1. **Всегда используйте `run.bat`** для запуска приложения
2. **Пересобирайте проект** после изменений в коде
3. **Проверяйте логи** в терминале приложения
4. **Запускайте из папки build** если возникают проблемы

## Получение помощи

Если проблемы не решаются:
1. Проверьте версии Qt и CMake
2. Убедитесь, что все зависимости установлены
3. Попробуйте запустить из корневой папки проекта
4. Проверьте права доступа к файлам
